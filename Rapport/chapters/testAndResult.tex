\chapter{Testing and results}


Ce chapitre se concentre sur les tests effectués pour évaluer la bonne fonctionnalité de notre algorithme, ses performances sur différents types d'entrées, et ses différences avec le \Naut{} originel.

The source code of our algorithm is available on \href{https://github.com/roro174/nauty.git}{GitHub}.

\section{Input and Output formats}

Avant de parler de nos tests, nous allons juste définir très brievement les formats d'entrée et de sortie de notre algorithme. 
The graph encoding is not fixed; however, we adopt the same approach as nauty, namely representing input graphs using the graph6 format~\cite{mckay_graph6_formats}. This choice enables more efficient testing of our algorithm.
