\section{Input and output formats}

Before presenting the experimental results, we briefly describe the input and output formats used by our implementation.

There is no universally fixed encoding for graphs used in isomorphism testing; however, following the convention set by \Naut{}, our implementation uses
the \emph{graph6} format~\cite{mckay_graph6_formats} to represent input graphs. This compact representation makes it easy to generate, store and exchange large graph datasets while remaining compatible with the tools commonly used in graph isomorphism research.

The program supports four execution modes:

\begin{itemize}
    \item\textit{iso:}\label{mode:iso} compares two graphs and outputs whether they are isomorphic.
    
    \item\textit{canonical:}\label{mode:canonical} computes and prints the canonical form of the input graph in graph6 format.
    
    \item \textit{all:}\label{mode:all} computes the canonical form of the input graph and, for every
    permutation explored, prints the resulting labelled graph. This mode is mainlyintended for debugging and validation.
    \item \textit{aut:}\label{mode:aut} computes the canonical form of the graph together with its automorphism group.
\end{itemize}

Moreover, the program allows the user to specify the invariant to be used for the canonical labelling. The available invariants are:
\begin{itemize}
    \item \textit{triangle}:\label{mode:triangle} \hyperref[algo:invariant_triangle_by_cell]{InvariantTriangleByCell};
    \item \textit{paths}:\label{mode:path} \hyperref[algo:invariant_two_paths_by_cell]{InvariantTwoPathsByCell};
    \item \textit{triple}:\label{mode:triple} \hyperref[algo:invariant_cell_triples_by_cell]{InvariantCellTriplesByCell};
\end{itemize}
